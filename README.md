# 中国象棋 · 智弈争雄 (Xiangqi Master)

> 正统中国象棋人机对弈与天梯积分排位系统，支持经典启发式深算与现代大模型 (LLM) 双引擎驱动，搭载国家级竞赛裁判规则与经典名局挑战。

---

## 🌟 核心特性

### 1. 正统象棋规则与专业裁判体系
- **七大兵种纯正规则**：严格实现仕士九宫斜行、相象田字塞象眼且不过河、马走日与蹩马腿、车横冲直撞、炮隔山打牛、兵卒过河前后与老底兵横行、将帅照面飞将禁制。
- **正规赛制裁判通则**：
  - **欠行困毙（判负）**：遵循中国象棋传统，无合法走步方直接判定判负。
  - **单方面长将（不变作负）**：严厉杜绝无赖连将，步步将军循环者强制判负。
  - **三度重复裁决**：同一局面循环三次且双方无违例时判和棋。
  - **60 回合自然限着**：双方连续 120 步（60 个完整回合）无吃子自动裁定和棋。
- **专业中文标准记谱**：完整呈现“炮二平五”、“马8进7”，并规范支持同列双子“前/后车”及同列三兵“前/中/后兵”。

### 2. 双引擎人机对弈体系
- **经典 Alpha-Beta 负极大值搜索引擎**：
  - 迭代加深搜索 (Iterative Deepening) + 毫秒级超时熔断，毫秒级即时响应，绝不卡死。
  - 静态搜索 (Quiescence Search) 解决吃子地平线效应。
  - 局面历史感知与防长将极值扣分机制，迫使电脑主动变招。
  - 四级梯次难度：初学棋童 (Elo 1100)、街坊棋手 (Elo 1400)、棋协大师 (Elo 1750)、特级大师 (Elo 2100)。
- **大模型 (LLM) 对弈引擎**：
  - 兼容 OpenAI 规范 API（支持 DeepSeek、GPT-4o、Claude 3.5、Qwen 等主流模型）。
  - 内置棋局转译提示词与战术心法解读，走棋同时提供战略思路剖析。
  - 本地引擎平滑兜底机制，遇到网络超时或模型输出异常时无缝接管，确保对局永不中断。

### 3. 天梯积分与排位段位体系
- 采用国际标准 Elo 算法，融入动态 K-factor 与连胜积分加成。
- 完整的晋阶段位：**业余九级** ➔ **业余六级** ➔ **业余三级** ➔ **业余一级** ➔ **候补大师** ➔ **特级大师**。
- 本地 LocalStorage 自动持久化战绩详单、胜率统计与最高连胜纪录。

### 4. 经典残局名局挑战
- 收录“七星聚会”、“野马操田”、“千里独行”等古谱经典名局。
- 独立 FEN 编解码，一键载入残局并随时展开实战破局。

### 5. 双人在线联机对弈与超时催促系统
- **纯前端 WebRTC P2P 架构**：零中央中转服务器、端到端直连传输，6 位房间码或链接一键复制邀请。
- **自定义执子与智能翻转**：房主可指定执红、执黑或随机抽签，客方棋盘自适应翻转保证第一人称视角。
- **正规落子无悔与局内协商**：在线禁用悔棋，支持双方在线“求和”协商与主动“认输”。
- **5 分钟超时防挂机与响铃提醒**：走棋思考超过 5 分钟自动弹出提示框并伴随清脆双音和弦提醒；支持随时手动一键催促走棋。
- **局内实时聊天**：内置“棋逢对手，请多指教”、“棋逢妙手，佩服佩服”等经典国风短语与自由文字畅聊。

### 6. 沉浸式国风视听体验
- **大气居中三栏布局**：740px 高清自适应木纹棋盘居中，左侧天梯计分与设置，右侧操作栏与实时棋谱。
- **纯 Web Audio 声音引擎**：零外部音频资源依赖，程序化合成木质落子、沉闷吃子、短促将军、催促响铃及宏大胜负和弦。
- **全局错误边界保护**：内置 React ErrorBoundary，杜绝白屏/黑屏，提供即时自愈恢复。

## 🌐 VPS 生产环境部署（无 Docker，零冲突）

本项目构建后为纯静态单页应用（SPA），无需任何后端服务或 Docker 容器，不干扰 VPS 现有运行中的其他业务项目。

### 方案 A：使用 Nginx 独立端口托管（推荐）

1. 将 `dist/` 目录上传至 VPS，如 `/var/www/xiangqi`：
```bash
rsync -avz --delete ./dist/ user@your-vps-ip:/var/www/xiangqi/
```

2. 在 Nginx 配置目录（如 `/etc/nginx/conf.d/xiangqi.conf`）添加独立配置（选择一个未被占用的端口，例如 `8088`）：
```nginx
server {
    listen 8088;
    server_name _;

    root /var/www/xiangqi;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # 启用 Gzip 压缩以加快棋盘静态资源加载
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml application/xml+rss text/javascript;
}
```

3. 测试并重载 Nginx（不重启服务，既有业务完全无感）：
```bash
sudo nginx -t && sudo nginx -s reload
```

### 方案 B：使用 Node / PM2 独立进程托管

无需修改 Nginx，利用轻量静态服务器 `serve` 运行在独立端口：
```bash
# 在 VPS 上全局安装 serve（如果尚未安装）
npm install -g serve pm2

# 启动并托管在指定端口（例如 8088）
pm2 start "serve -s /var/www/xiangqi -l 8088" --name "xiangqi-game"

# 保存 PM2 进程状态以支持开机自启
pm2 save
```
